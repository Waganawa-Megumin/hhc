# HHC 起動ガイド（GitHub Codespaces）

毎回の起動から、最新の取り込み・トラブル対処・停止までの操作手順です。

---

## ⚡ TL;DR（毎回これだけ）

1. <https://github.com/codespaces> で対象の Codespace を開く（または リポジトリ → **Code ▸ Codespaces**）
2. 開くと自動で起動します（VS Code の dev タスク）。数十秒待つ
3. 下部の **「PORTS（ポート）」タブ → `5173` → 🌐（Open in Browser）** をクリック

> 自動起動しない／止まっている時は、ターミナルで `npm run dev` を実行してから 5173 を開く。

---

## 1. 前提（初回セットアップ・一度だけ）

Codespaces の**シークレット**を登録しておきます（GitHub → リポジトリ → **Settings ▸ Secrets and variables ▸ Codespaces**）。
シークレットを追加・変更したら **Rebuild Container**（後述）で反映。

最低限：
- `HHC_KEY` … Anthropic APIキー（§6 解析・§7 OSINT 用）※ `ANTHROPIC_API_KEY` でも可

任意（あると機能が増える）：
- `HHC_DB_KEY` … 案件履歴（暗号化DB）用パスフレーズ
- `HHC_OPENSANCTIONS_API_KEY` / `HHC_TRADEGOV_API_KEY` / `HHC_GBIZ_INFO_API_KEY` … 制裁・法人照合

> シークレットが無くても **第1層（チェックリスト＋スコア）** は動きます。

---

## 2. 毎回の起動手順（詳細）

1. **Codespace を開く**：<https://github.com/codespaces> → 対象を開く（無ければ リポジトリ → Code ▸ Codespaces ▸ Create）
2. **自動起動を待つ**：`HHC dev` タスクが `npm run dev`（エージェント＋Web）を起動します
   - 「Allow automatic tasks?」が出たら **Allow**
3. **起動を確認**：ターミナルに次の**両方**が出れば成功
   - `VITE v5...  ready` と `➜ Local: http://localhost:5173/`
   - `[hhc-agent] http://127.0.0.1:8787  model=... key=true caseDb=true`
     - `key=false` → Anthropicキー未注入（→ Rebuild）／`caseDb=false` → `HHC_DB_KEY` 未注入
4. **ブラウザで開く**：下部 **PORTS タブ → `5173` の行 → 🌐 Open in Browser**
   - 「Open in Preview」でエディタ内に開いてもOK
   - ⚠️ 自分のPCで `localhost:5173` を直打ちしても繋がりません。**必ず PORTS タブのリンクから**

自動起動しない場合は、ターミナルで手動起動：
```bash
npm run dev
```

---

## 3. 2つ目のターミナル（コマンド用）

`npm run dev` は起動しっぱなしの常駐プロセスなので、そのターミナルは占有されます（正常）。
**別コマンド（`git pull` 等）は2つ目のターミナルで**：

- ターミナルパネル右上の **`+`（New Terminal）**、または **Terminal ▸ New Terminal**

---

## 4. 最新を取り込む / シークレットを反映

2つ目のターミナルで：
```bash
git pull
```
- 通常は `tsx watch`（エージェント）と Vite HMR（Web）が**自動再読込**。ブラウザを更新すればOK
- 反映が怪しければ、dev ターミナルを **Ctrl+C → `npm run dev`** で再起動

ケース別：
- **依存パッケージが増えた**（`Cannot find module ...` が出る）→ `npm install` してから `npm run dev`
- **シークレットを追加/変更した** → **Rebuild Container**（F1 →「Codespaces: Rebuild Container」）。`data/` の案件DBは保持されます

---

## 5. トラブルシュート

| 症状 | 対処 |
|---|---|
| PORTS に `5173` が出ない | サーバ未起動。ターミナルで `npm run dev`。出力にエラーが無いか確認 |
| `Cannot find module ...` | `npm install` → `npm run dev`（pullで依存が増えた時） |
| ブラウザで開けない | `localhost` 直打ちではなく、**PORTS タブの 🌐** から開く |
| `5174` 等になっている | 5173 が使用中。ログに出た実際のURL/ポートを使う |
| `key=false` のまま | Anthropicキー未注入 → Rebuild Container（または Stop→Start） |
| `caseDb=false` のまま | `HHC_DB_KEY` 未注入 → Rebuild |
| OSINTで `unavailable` | そのソースのキー未設定（`sanctions_opensanctions`=OpenSanctions、`screening_us_csl`=Trade.gov 等） |
| しばらく放置で繋がらない | Codespace は約30分無操作で自動停止。<https://github.com/codespaces> から再開 → `npm run dev` |

---

## 6. 停止と案件履歴の保全

- **サーバ停止**：dev ターミナルをクリック → **Ctrl+C**
- **Codespace 停止**：<https://github.com/codespaces> → 対象 → Stop（コンピュート時間の節約）
- ⚠️ **案件履歴（`data/` の暗号化DB）は、Codespace を「削除」すると失われます**（Stop/Start・Rebuild では保持）。
  - 長期保存したい場合は、アプリの「案件履歴」パネルで **暗号化エクスポート（.age）** をダウンロード → 別Codespace（同じ `HHC_DB_KEY`）で **インポート**

---

## 7. シークレット早見表

| 名前 | 用途 | 必須 |
|---|---|---|
| `HHC_KEY`（or `ANTHROPIC_API_KEY`） | §6 解析・§7 OSINT（Anthropic API） | §6/§7に必須 |
| `HHC_DB_KEY` | 案件履歴の暗号化DB | 任意 |
| `HHC_OPENSANCTIONS_API_KEY` | 制裁/PEP/METI 照合（OpenSanctions） | 任意 |
| `HHC_TRADEGOV_API_KEY` | 米 CSL（OFAC/BIS Entity List 等） | 任意 |
| `HHC_GBIZ_INFO_API_KEY` | gBizINFO（国内法人・補助） | 任意 |
| `HHC_HOUJIN_APP_ID` | 国税庁 法人番号（国内法人・一次） | 任意 |
| `HHC_OPENCORPORATES_TOKEN` | OpenCorporates（海外法人・任意） | 任意 |

> 海外法人の実在確認は **GLEIF（`corp_gleif`）がキー不要**で動くため、OpenCorporates は無くても構いません。

## 限定デモ共有（ログイン不要・公開ポート）

数名にURLを渡して**ログイン不要**で見せる方法。Codespaceは**あなたが起動している間だけ**動くので、API課金もあなたの管理下です。

> 公開するのは **5173（Web）だけ**でOK。バックエンド(8787)はViteが内部でプロキシするので公開不要・非公開のままにします。

**手順A：PORTSタブから（GUI）**
1. 下部 **PORTS タブ** → `5173` の行を**右クリック**
2. **Port Visibility → Public** を選択
3. `5173` の **Forwarded Address**（`https://〜-5173.app.github.dev`）をコピーして共有

**手順B：ターミナルから（CLI・速い）**
```bash
gh codespace ports visibility 5173:public -c "$CODESPACE_NAME"
```
URL確認: PORTSタブ、または `gh codespace ports -c "$CODESPACE_NAME"`

**デモ終了後（推奨）**
- 非公開に戻す: `gh codespace ports visibility 5173:private -c "$CODESPACE_NAME"`
- または Codespace を **Stop**（<https://github.com/codespaces>）

**注意**
- **Public = URLを知る全員が認証なしでアクセス可**。§6/§7はあなたのAnthropicキーを使う（課金）。URLは不特定多数に貼らない。
- 案件DBのエンドポイント（recall/stats/export）も触れます。デモでは**機微な案件データを入れない**、または **`HHC_DB_KEY` を外して起動**（案件履歴オフ）も選べます。
- 組織ポリシーで公開ポートが禁止されていると **Public がグレーアウト**します（個人リポジトリなら通常は可）。
- Codespaceは約30分無操作で自動停止。デモ中は操作を続けるか、停止後は再開してください。
