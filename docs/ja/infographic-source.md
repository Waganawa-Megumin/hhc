# HHC（Human Hunter Check）— インフォグラフィック用ソース

> NotebookLM 等に**ソース**として取り込み、HHC の概要インフォグラフィックを生成するための1枚資料です。数値・カテゴリ・対比が図にしやすいように構造化しています。事実ベースで、誇張・断定はしません。

## 1行サマリ
HHC は、**求人スカウト・応募者・受託者・来客者など「怪しいと感じた相手」が、なりすましや外国情報機関の勧誘ではないか**を自己診断し、**公開・適法なOSINT**で裏取りする、**ローカル優先**の自衛ツール。出力は**リスク帯域（低・中・高）＋推奨アクション**だけ。

## これは何か / 何でないか
- ✅ 自衛のための**自己トリアージ**（指標チェック＋スコア＋裏取り）。
- ✅ 出力は**リスク帯域＋推奨行動**のみ。
- ❌ 個人を「スパイ」と**断定・ラベリングしない**。有罪/無罪を決めない。
- ❌ 国籍・民族を**自動スコアの軸にしない／自動推論しない**。
- ❌ LinkedIn本体のスクレイピングやログイン背後アクセスは**しない**（公開・適法な情報源のみ）。
- 原則：**「証拠なし＝無実ではない」**（リスト不掲載でスコアは下げない）。

## 想定シナリオ（3つ）
1. **あなたが標的**：求人・ヘッドハンティングを装った勧誘（偽コンサル/シンクタンク → 機密アクセスの見極め → 報酬と引き換えに情報要求）。
2. **あなたが採用・発注側**：応募者・フリーランス受託者の**なりすまし**（偽の身元で採用/受託し、システム・データ・コードへアクセス。例：北朝鮮IT労働者詐欺）。
3. **対面・来客など**：取材・営業・視察・会議で接触する相手の見極め。

## 背景（準拠する警告・枠組み）
- 2026年 ファイブ・アイズ共同警告（求人サイト等での機密アクセス者勧誘）
- 英 NPSA「Think Before You Link」/「Applicant Beware」
- 日本・公安調査庁の経済安全保障ガイダンス
- ファイブ・アイズ/FBI：なりすましIT労働者（北朝鮮等）の不正就労・委託への警告

## 7つの指標カテゴリ（A–G）
| 記号 | カテゴリ | 何を見るか（例） |
|---|---|---|
| **A** | 相手の実体性 | Web実体が薄い／ドメインが新規／報酬過大／法人登記と矛盾 |
| **B** | アカウント真正性 | 写真が生成画像・使い回し／つながり極少・新規／経歴が検証不能／連絡経緯が不自然 |
| **C** | コミュニケーション挙動 | 顔出し回避／早期に暗号化アプリ・対面へ誘導／急速にエスカレート／外部URL・急かし |
| **D** | 要求・狙い | 非公開情報/所属/アクセス権を聞く／機微分野のレポート要求／**報酬と引き換えの情報提供**／非正規の支払い |
| **E** | 標的属性（係数） | あなた側の条件：機密/先端技術アクセスあり、政府・防衛・研究の現/元関係者 |
| **F** | 制裁・輸出管理・リスト合致 | 募集元/個人/**所属機関**が指定リストに合致（人手確認） |
| **G** | 国家ネクサス（人手設定・任意） | 申告/判明した国籍・出身・国家所属が、設定した懸念国/懸念機関に該当（人手判断・自動推論なし） |

> 図解時の注意：**A–G は7つの別カテゴリ**。各行の例示シグナルは**そのカテゴリ固有**で、他カテゴリと**重複させない**こと（A=実体性 / B=アカウント真正性 / C=挙動 / D=要求 / E=標的係数 / F=リスト合致 / G=国家ネクサス）。

## スコアリング（数値で図示しやすい）
- **計算式**：`スコア = 該当指標の重みの合計 × 標的係数`（**E1 ×1.3**、**E2 ×1.2**）。
- **リスク帯域**：**低 0–5 / 中 6–12 / 高 13+**。
- **クリティカル指標（点数に関わらず『高』へ強制昇格）**：
  - **D3**：報酬と引き換えの情報提供（単独で発動）
  - **C2＋D1**：暗号化誘導 ＋ 非公開情報/アクセスの探り（同時）
  - **F1**：指定リスト合致（**人間が同定を確認**）
- **F の扱い**：**F1=+5（人間確認・クリティカル）／F2=+3／F3=0（弱い一致は参考のみ・非加点）**。
- 決定論スコアが**常にAIの提案に優先**。

## OSINTで裏取りする公開ソース
ドメイン登録（RDAP）／証明書ログ（crt.sh）／Web検索／国内法人（国税庁 法人番号・gBizINFO）／海外法人（GLEIF・OpenCorporates）／**制裁・PEP・ウォッチリスト（OpenSanctions ＋ METI外国ユーザーリスト）**／**米 CSL（OFAC SDN・BIS Entity/Unverified/MEU 等）**／画像の使い回し（リバース画像検索の導線）。
> 照合リスト例：OFAC SDN・BIS Entity/Unverified/MEU・UN・EU・英OFSI・METI外国ユーザーリスト・PEP。

## 推奨アクション（4R・帯域別）
- **低**：通常対応。記録のみ。煽らない。
- **中**：慎重に。追加照会・本人確認、記録を保全。
- **高（Report & Remove）**：エンゲージを停止し、証拠を保全し、所属組織のCSIRT／公安調査庁等へ通報。

## プラットフォーム & セキュリティ
- **ローカル優先**：第1層（チェックリスト＋スコア）は鍵もネットも不要・端末内完結。
- **暗号化**：案件履歴は暗号化DB（SQLCipher）。エクスポートは age 暗号化。APIキーは常にサーバ側。
- **アカウント/認証（任意）**：Admin/User の2ロール、パスワード（scrypt）＋**MFA（TOTP／メール）**、招待リンクでの初期設定、ログインロックアウト。
- **監査ログ＆ダッシュボード（Admin限定）**：日時・User-Agent・**アクセス元IP＋ロケーション**・操作内容・検索キーを記録。保持期間で自動削除、CSV/JSONエクスポート、SIEM（Splunk等）転送。

## 数値で見る HHC（Key facts）
- リスク帯域：**3段階**（低 0–5 / 中 6–12 / 高 13+）
- 指標カテゴリ：**7**（A–G）
- クリティカル昇格トリガー：**3**（D3 ／ C2+D1 ／ 人間確認F1）
- 標的係数：**E1 ×1.3**、**E2 ×1.2**
- F の重み：**F1=5 / F2=3 / F3=0**
- OSINT 公開ソース：**約10種**（鍵不要のものはそのまま稼働）
- MFA方式：**2**（TOTP・メールコード）
- 言語：**日本語 / 英語**

## ガードレール（やらないこと）
「スパイ」等のラベル付けをしない／二値の有罪判定をしない／国籍・民族を自動加点も自動推論もしない／公開・適法な情報源のみ／リスト合致やクラスタ統合は**人間が確認**してから加点／決定論スコアが常にAIに優先／「証拠なし≠無実」。
